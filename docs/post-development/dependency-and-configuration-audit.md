## 2. Configuration Architecture

### 2.1 Settings Management (`agentshield.core.config.Settings`)
All configuration parameters are modeled using Pydantic `BaseSettings`:
- Environment variables take precedence over `.env` files.
- Default fallbacks exist for local developer environments (e.g. SQLite database, local debug mode).

## 3. Vulnerability & Supply Chain Assessment

1. **Version Pinning:** All dependencies use semantic version constraints with explicit upper bounds (e.g. `>=2.9,<3.0`), preventing breaking upstream changes.
2. **Cryptographic Primitives:** Industry-standard Argon2 and HMAC-SHA256 are used in place of deprecated algorithms (MD5, SHA1, plain DES).
3. **Python 3.14 Compatibility:** The test suite and application run cleanly on the latest Python runtime (`3.14.0`) as well as `3.11+`.
